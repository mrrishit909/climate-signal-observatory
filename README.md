# Climate Signal Observatory: data layer

"The Planet Is Speaking in Data." Precomputed, versioned JSON and binary artifacts (no backend) from NASA GISTEMP v4, HadCRUT5 5.2.0.0, NOAA GML CO2 and IPCC AR6 Table SPM.1,
for a static GitHub Pages site (design and site source live in `design/` and `site/src/`).

```
uv sync
uv run python -m pipelines.run_all --fetch   # download raw (gitignored), clean, analyse, write site/public/data/ (about 1 minute)
uv run pytest -q
```

- `docs/PROBLEM.md`, `DATA_SOURCES.md`, `DATA_CONTRACTS.md`, `METHODOLOGY.md`, `TESTING.md`, `LIMITATIONS.md`
- `data/contracts/*.schema.json`: the JSON Schema for every artifact (generated by `pipelines/contracts.py`)
- `site/public/data/facts.json`: the single source for every number in site copy; `meta.json`: source hashes, versions, licences, limitations
- Honesty tags on every field: OBSERVED / DERIVED / PREDICTED (IPCC, quoted) / SIMULATED / SYNTHETIC.
