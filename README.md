# Climate Signal Observatory

"The Planet Is Speaking in Data." Precomputed, versioned JSON and binary artifacts (no backend) from NASA GISTEMP v4, HadCRUT5 5.2.0.0, NOAA GML CO2 and IPCC AR6 Table SPM.1,
for a static GitHub Pages site (source in `site/`).

```
uv sync
uv run python -m pipelines.run_all --fetch   # download raw (gitignored), clean, analyse, write site/public/data/ (about 1 minute)
uv run pytest -q
```

- `docs/PROBLEM.md`, `DATA_SOURCES.md`, `DATA_CONTRACTS.md`, `METHODOLOGY.md`, `TESTING.md`, `LIMITATIONS.md`
- `data/contracts/*.schema.json`: the JSON Schema for every artifact (generated by `pipelines/contracts.py`)
- `site/public/data/facts.json`: the single source for every number in site copy; `meta.json`: source hashes, versions, licences, limitations
- Honesty tags on every field: OBSERVED / DERIVED / PREDICTED (IPCC, quoted) / SIMULATED / SYNTHETIC.

## The site

"The Planet Is Speaking in Data": a scroll-driven story over a WebGL2 globe that unwraps into an equal-area map and a vertical core of yearly strata (the "core sample"). Scenes: SIGNAL, RECORD, YEARS, REGIONS, STRATA, ZERO (choose your baseline), FUTURES (AR6 windows), EVIDENCE, OBSERVATORY (any year, any place, any zero), then a closing surface. Everything is read from the precomputed artifacts; the browser computes only cheap derivations (rebasing a grid by its per-cell offset, zonal means, ranks) that are tested for parity against the Python reference.

Live site (placeholder until deployed): https://mrrishit909.github.io/climate-signal-observatory/

Part of The Data Frontier program (project 03). Status: `docs/BUILD_STATUS.md`. It is an educational explainer on public climate records, not a forecast and not a climate model.

| Path | What |
|---|---|
| `pipelines/` | Offline pipeline: ingestion (checksummed), cleaning, modeling (grids, trends), publishing, JSON Schema generation. Entry point `pipelines/run_all.py` |
| `analytics/` | Baseline rebasing, trend and interval statistics, geography, zonal means |
| `data/contracts/` | JSON Schema per artifact |
| `data/manifests/` | Raw file manifest with sha256, cleaning ledger |
| `site/` | Vite + React 18 + TypeScript static site, raw WebGL2 globe, Canvas2D scenes, Lenis scroll |
| `site/public/data/` | Published artifacts: JSON plus pre-gzipped `.i8.bin.gz` Int8 grids with `.meta.json` sidecars |
| `tests/` | pytest: contracts, baselines, trends, quality, requested-by-design artifacts, reconciliation |

## Reproduce

Requires Python 3.12+ with [uv](https://docs.astral.sh/uv/) and Node 24. The raw downloads are about 60 MB.

```bash
# 1. Data pipeline
uv sync
uv run python -m pipelines.run_all --fetch
uv run pytest -q          # the 4 reconciliation tests that re-read raw files skip themselves when data/raw is absent

# 2. Site (the published artifacts are committed, so this works without step 1)
cd site
npm ci
npm run typecheck && npm run lint && npm test
npm run build && npm run preview    # http://localhost:4321/climate-signal-observatory/
npm run e2e                         # Playwright against the production build
```

The data is re-published monthly by the sources; `site/public/data/meta.json` records the vintage and hashes of the run that produced the committed artifacts.

## Honesty tags

Every number on the site carries one of these tags, visible in the UI.

| Tag | Meaning |
|---|---|
| OBSERVED | Read directly from the source files (or an IPCC-assessed observation, quoted) |
| DERIVED | Deterministic computation on observed data (rebased anomalies, trends, ranks, extremes) |
| PREDICTED | IPCC AR6 scenario ranges, quoted. This project makes no forecasts |
| SIMULATED | Method checks on synthetic noise (interval coverage). Never presented as climate data |
| SYNTHETIC | Generated stand-in data. This project publishes none; the tag exists for the program |
