# Data contracts

Grain, keys, units and rules. Enforced by JSON Schemas (`data/contracts/*.schema.json`, generated by `pipelines/contracts.py`) and
`tests/`. All artifacts live in `site/public/data/`, versioned `schema_version: "v1"`, and carry a `tags` object mapping each
top-level field to OBSERVED / DERIVED / PREDICTED / SIMULATED (SYNTHETIC unused).

## Conventions
- Anomalies are degrees Celsius (K difference), rounded to 3 decimals. `null` = missing (never 0, never infilled).
- Baselines: `"1850-1900"` (HadCRUT5 only, GISTEMP starts 1880), `"1951-1980"`, `"1991-2020"`. Series that cannot be computed on a baseline simply omit that key.
- Time axes: annual series share one `years` axis (1850..latest complete year); GISTEMP is `null` before 1880.
  Monthly series use `start` ("1850-01") + equal-length arrays.
- Annual value = mean of the 12 monthly anomalies after monthly rebasing, for complete calendar years only. The partial current year is excluded.
- Baseline conversion (series): per calendar month m, offset_m = mean over reference years of the series' native monthly anomaly (all 12 months need >= 80% of reference years).
  rebased = native - offset_m. Annual-equivalent offset = mean of the 12 offsets. Recorded in `series_annual.conversions`.
- Baseline conversion (grids): per cell, offset = mean of the cell's stored annual anomalies over the reference years (needs >= 80% valid). Client computes `stored - offset`.
  This is annual-level rebasing; it differs from month-level rebasing by less than about 0.01 C in complete cells (tested).
- Trend unit: degC per decade. CIs are 95%.

## Grid encoding
- Binary = gzip of a C-order Int8 array `[year][lat][lon]`, rows north to south, columns west to east, value = round(anomaly / 0.1 degC), -128 = missing.
  Valid range -127..127 = +/-12.7 C (observed annual extremes are about +/-6.5 C, so nothing clips; the count is recorded).
- The page decompresses with `new Response(blob.stream().pipeThrough(new DecompressionStream("gzip")))` (GitHub Pages does not content-encode `.gz` binaries, so the file is pre-compressed and the size is the transfer size).
- Sidecar `*.meta.json` holds grid geometry, year range, per-year valid cell counts, and per-baseline per-cell offsets in 0.01 C units (`null` = baseline unavailable for that cell).
  Decode: `value_c = byte * 0.1; rebased = value_c - offset * 0.01`.
- Trade-off: 0.1 C steps give a worst-case quantization error of 0.05 C (typical cell annual noise is >0.3 C), and a 2 degree grid keeps real structure while the gzip stays near 0.6 MB (146 years x 16,200 cells = 2.4 M bytes raw). A 4 degree version would be about 0.2 MB but loses coastal and island detail. Both grids together are under 1.5 MB.
- Year-major layout compresses better (0.60 MB) than cell-major (0.86 MB) for the 2 degree grid, and delta coding made it worse (0.69 MB): measured, not assumed.

`regional.land_ocean.grid_land_mask` adds land-cell vs ocean-cell means from the grids (approximate). Latitude bands have edges on multiples of 10 degrees.

Full per-artifact field lists are in the JSON Schemas; `tests/test_contracts.py` validates every produced artifact against them.
