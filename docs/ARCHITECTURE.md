# Architecture

Two halves joined by a contract: an offline Python pipeline that turns the raw climate files into small JSON and Int8 binary artifacts, and a static browser site that only reads those artifacts.

```
data/raw (gitignored)           pipelines/ingestion/fetch.py     (sha256 per file -> data/manifests/raw_manifest.json)
   -> cleaning + accounting     pipelines/cleaning/clean.py      (ledger -> data/manifests/cleaning_ledger.json)
   -> modeling                  pipelines/modeling/              (series, grids, cell trends; uses analytics/*)
   -> site/public/data/*        pipelines/publish.py             (tracked: JSON, *.i8.bin.gz, *.meta.json sidecars)
   -> data/contracts/*.json     pipelines/contracts.py           (JSON Schema per artifact)
```

Entry point: `pipelines/run_all.py` (`--fetch`). Shared paths and constants: `pipelines/common.py`.

## Pipeline and analytics

- `analytics/core.py`: explicit baseline rebasing (per calendar month for series, per cell for grids). A baseline a product cannot support is refused, not approximated.
- `analytics/stats.py`: OLS trend with naive, AR(1)-adjusted (primary) and Newey-West HAC intervals, LOESS with block-bootstrap band, piecewise-linear change points, coverage simulation.
- `analytics/geo.py`, `analytics/zonal.py`: latitude bands, cos(lat) weights, land fraction, the zonal-mean rule (row needs at least 20% observed cells) that the browser repeats.
- Method detail: `docs/METHODOLOGY.md`. Field detail: `docs/DATA_CONTRACTS.md`.

## Data contract

`data/contracts/*.schema.json` (generated by `pipelines/contracts.py`) cover the artifacts in `site/public/data/`. `facts.json` is the single source of every number in site copy. Grids are Int8 at 0.1 C (cell trends at 0.01 C/decade), stored pre-gzipped as `.i8.bin.gz` with a `.meta.json` sidecar (shape, scale, per-cell reference offsets, sha256 of the uncompressed bytes). `zonal_fixture.json` and the cell-trend grids let the TypeScript ports be tested against Python.

## Site (`site/`)

Vite, React 18, TypeScript strict, Tailwind CSS v4, Lenis smooth scroll, raw WebGL2 for the globe (no three.js), d3-geo for projection math. Base path `/climate-signal-observatory/` (`site/vite.config.ts`), `appType: "mpa"` so a missing artifact is a real 404 as on Pages. Static output, no server.

| Area | Files | Role |
|---|---|---|
| Shell | `src/main.tsx`, `src/app/{App,scenes,useIntro,ErrorBoundary}` | Scene registry (`scenes.ts`: ids, track heights, landing points), intro, error boundary |
| Data layer | `src/data/{loader,grid,artifacts,types,copy,useArtifact}.ts` | Typed loaders with initial/loading/ready/empty/error/retry states; `grid.ts` fetches `.i8.bin.gz` with byte progress, gunzips only if the 1f 8b magic is present, verifies the sidecar sha256 |
| Scroll | `src/scroll/{engine,hooks,Track}` | Tracks register sections; progress computed once per frame |
| Motion | `src/motion/{loop,ease,tween,progress,reveal,useTweened}.ts` | One rAF loop; easing, tweens, stepped progress |
| GL | `src/gl/{globe,projection,shaders,frame,paint2d}.ts` | WebGL2 globe and map from one cell mesh with an Equal Earth blend; `paint2d.ts` is the flat Canvas2D fallback when WebGL is unavailable |
| Graphics | `src/graphics/{canvas,orb}.ts`, `src/scenes/{director,frames,geometry}.ts` | Orb and scene state computed from (scene, progress, time) |
| Models | `src/model/{trend,zonal,rank,bins,futures,format}.ts` | Browser ports (trend, zonal rule, ranks, bench bins) tested against Python artifacts |
| State | `src/state/{climate,bank,motion,scenes}.ts` | Shared year/baseline/source selection, tier and reduced-motion state |
| Scenes | `src/scenes/S01Signal` ... `S08Surface`, `Observatory` | See the table below |
| Components | `src/components/` | WordReveal, Nav, StoryCard/Deck, Orb, HonestyChip, Tooltip, StateUI, NotificationCard |
| Dev | `src/dev/Gallery.tsx` | Component gallery (`npm run build:gallery`), not part of the production page |
